# KiCad 課程統一學習入口

這裡集中管理本專案的 15 個課程，沿用第 1 課已採用的學習方式：每次做一小步，回報結果或貼上截圖，解決眼前問題後再往下。網頁整理課程與進度，聊天提供操作引導，兩邊共用同一份紀錄。

新使用者從第 1 課開始，全部課程都尚未開始。若本機缺少 `progress.json`，入口會依空白範本自動建立；已存在的個人進度會保留。第 1 課公開完成範例只是參考，不會使任何課程自動完成。

## 開啟統一窗口

1. 在檔案總管開啟下載後的 `Kicad-7-Series` 專案根目錄。
2. 連按兩下 `Start-Learning.cmd`，依啟動結果開啟本機學習頁面，預設網址為 `http://127.0.0.1:8765`。
3. 在左側章節欄選擇章節，直接打開要做的那一節。需要結束本機服務時，執行根目錄 `Stop-Learning.cmd`。

啟動程式會使用 `learning/Start-Learning.ps1`。本機頁面需要 Python 3.10 以上；若啟動顯示找不到 Python 或網址無法連線，把完整訊息貼回對話即可。頁面關閉後，已儲存的進度仍在專案中。

## 每課怎麼學

1. 選擇課程，使用該課的練習專案入口。全部 15 課都先建立自己的副本，再開啟 KiCad。
2. 把「複製接續訊息」的內容貼到對話，讓教師知道目前課程和步驟。
3. 依對話完成一個小目標。完成後回報結果；看不懂時，直接說「沒看到」並貼當前截圖。
4. 確認達到該步的成功畫面後，再確認完成。若已在網頁確認，對話會讀取最新進度，不需重複登記。

網頁提供課程、步驟、檔案和進度；詳細操作、截圖判讀及卡關處理在 AI 助教對話中進行。助教需能存取本機專案並遵循 `AGENTS.md`，不限定特定產品。

### 頁面上的引導

頁面分成 **16 章、33 節**：第 00 章是常用功能與快捷鍵速查，不計入進度；第 01～15 章對應原教材 15 課，每章分 2～4 節，節底下是原本的 90 個小步（ID 不變，舊進度直接沿用）。修訂範圍、內容依據及待補畫面見 [講義修訂紀錄](../docs/TEACHING_REVIEW.md)。

- **一節一頁**：一節的全部小步依序排在同一頁，左邊文字、右邊 KiCad 10 實拍。每步依序是「一句重點 → 怎麼做（編號對應圖上位置）→ 做完應該看到 → 常見失誤 → 找不到位置？」。點圖會放大，放大後仍保留編號，也能開啟原圖。
- **不限制順序**：任何一節都能直接打開，小步可以不照順序記錄；每一步仍要你實際做完才按「我做完了，記錄這一步」。
- **想一想**：觀察型小步附一題選答，幫助確認看懂畫面，不會擋住記錄。
- **自動檢查**：能從檔案判斷的步驟（是否開對練習副本、是否已存檔、ERC、DRC、封裝、輸出檔與 ZIP），按「先檢查一次」即可看到結果。記錄完成時會再檢查一次，必要項目沒過就不會記錄。找不到 `kicad-cli` 等原因造成必要檢查無法執行時，仍可記錄，但會標成「無法自動驗證」，不算工具通過。
- **版本差異警告**：KiCad 10 開 KiCad 7 教材時一定會出現幾則元件庫版本警告。檢查結果會標成「可忽略」並說明原因，只有沒標的項目需要處理。
- **圖片用途**：每張圖標明是「KiCad 10 操作實拍（教材暫存副本）」「學員原始截圖」或「原教材參考圖」。
- **本課收尾**：每章最後一節附本課完成標準、一題選做的**練習題**（和主線分開記錄），第 1、12、15 章另有**實體結果**（製板、焊接、上電），只有你實際做了並回報才記錄。
- **本課資源**：每節頁尾的「本課資源、筆記與重新學習」收原作者影片、教材檔案、卡關筆記與重新學習。
- **側欄**：章節欄可展開或收合；寬螢幕收合後只留 0、1、1.1… 編號，窄螢幕改成抽屜。舊版一次一步的頁面保留在 `/legacy.html`。

## 15 課與工作副本

實際課程名稱、原教材路徑、可用專案檔、分節、操作步驟與練習題集中在 [課程目錄](catalog.json)；第 00 章速查在 [reference.json](reference.json)。原始專案介紹保留於 [原教材 README](../README.md)。

| 內容 | 儲存位置與用途 |
|---|---|
| 原始課程教材 | 專案根目錄原有的 15 個課程資料夾，保留作為參考。 |
| 第 1 課完成範例 | `docs/examples/led-board/`，包含範例設計與製板輸出。 |
| 個人練習 | `learning/workspaces/01/` 至 `learning/workspaces/15/`，由入口按需建立獨立副本，不納入 Git。 |
| 空白進度範本 | [progress.template.json](progress.template.json)，新安裝從全部未開始起步。 |
| 唯一個人進度 | `learning/progress.json`，自動建立，網頁與教師命令列共用，不納入 Git。 |
| 個人問題與解法 | `learning/journal/`，保存操作脈絡，不納入 Git。 |
| 重新學習的封存 | `learning/archive/<課號>-<時間>/`，內有舊練習副本與當時的進度快照，不納入 Git。 |
| 個人檢查證據 | `learning/evidence/`，不納入 Git。 |
| 教學圖 | [assets](assets/)，依實際畫面標示需要操作的位置。 |

副本中若有教材原先就附帶的 PCB 或製板檔，屬原作者的參考成果。檔案存在不代表已完成。

## 新對話如何接續

先在學習頁面選擇課程，再按「複製接續訊息」，貼到新對話。如果當時無法開啟頁面，也可以貼上：

```text
請接續 <專案根目錄完整路徑> 的 KiCad 引導式學習。
先讀 AGENTS.md、learning/catalog.json、learning/progress.json 與相關 journal，
依最新進度每次教我一個小目標，給 1 至 3 個操作及可見的成功判準。
等我回報完成再進下一步；如果我說沒看到，請依當前截圖縮小操作並標示位置。
```

教師會重新讀取檔案中的最新狀態，因此不必在不同對話各維護一份進度。老師的完整規範見根目錄 [AGENTS.md](../AGENTS.md)。

## 進度如何保存

每次確認完成或儲存筆記，都由共用狀態程式處理 revision 檢查、鎖定與原子寫入。前端不使用 `localStorage` 另存完成度，只記住側欄展開與收合。若同時有網頁及對話更新，版本衝突時先重新整理並核對目前步驟。

教師可在專案根目錄執行以下命令讀取進度：

```text
python .\learning\manage.py status
```

進度寫入使用 `manage.py record`；不要用文字編輯器直接修改 `progress.json`。學員確認、截圖、檔案檢查和工具驗證會依證據強度分開記錄，完成某個操作不會自動被解讀為已實際製板或點燈。

## 重新學習

想把一課從頭再做一次：

1. 先在 KiCad 用「檔案 → 關閉專案」關掉該課專案。
2. 在該章任一節頁尾展開「本課資源、筆記與重新學習」，按 **重新學習本課**，再按 **確定重新開始**。要全部重來，到「課程總覽」按 **全部課程重新開始**。
3. 該課回到第 1 步。再按「開啟練習專案」會從原教材建立全新的副本。

重新開始不會刪除任何東西：舊練習副本與當時的進度、筆記、證據會封存到 `learning/archive/`，原教材與其他課程不受影響。KiCad 仍開著該課專案時會拒絕執行；若 KiCad 其實已關閉卻仍被拒絕，是上次異常結束留下的鎖定檔，到該課練習資料夾刪除以 `~` 開頭的 `.lck` 檔即可。命令列對應操作為 `python .\learning\manage.py reset --lesson 03 --revision <n> --yes`（`--lesson all` 為全部課程）；只有學員明確要求時才由教師執行。

完整的問答、卡關與成果示範，見 [公開學習紀錄範例](../docs/examples/lesson-01.md)。自己的進度和練習成果請另行備份。

若重置中途失敗，程式會嘗試還原進度、事件紀錄及副本；副本無法搬回或進度無法還原時，會保留封存目錄與 `progress-full-before.json` 完整進度備份，並明確顯示位置，不會刪掉封存中的成果。看到「部分回復未完成」時先停止重試，依訊息核對備份再請助教協助還原。程式突然被終止時也應先核對封存資料，目前不會自動完成中斷的交易。

處理殘留鎖定檔前，請確認相關的 KiCad 管理員、原理圖與 PCB 編輯器已全部關閉；不要只因看到鎖定檔就刪除它。
